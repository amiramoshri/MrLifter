# Mr. Lifter - מערכת ניהול אימונים מתקדמת

## 🎯 סקירה כללית

**Mr. Lifter** היא אפליקציית ווב מתקדמת לניהול אימונים ומעקב התקדמות בחדר כושר. האפליקציה מיועדת למתאמנים ומאמנים המעוניינים במעקב מקצועי ומדויק אחר האימונים שלהם.

## ✨ תכונות עיקריות

### 👤 ניהול משתמשים
- מערכת אימות מאובטחת עם Supabase Auth
- פרופיל אישי מפורט (שם, משקל, גובה, גיל, BMI)
- אבטחת נתונים עם Row Level Security (RLS)

### 📅 תוכניות אימון
- תוכניות חודשיות מובנות (אוגוסט, ספטמבר, אוקטובר)
- תוכניות יומיות מפורטות עם תרגילים, סטים, חזרות ומשקלים
- אפשרות לבחירת תרגילים ישירות לרישום אימון

### 📝 רישום אימונים
- מערכת Workout A/B לסוגי אימונים שונים
- רישום מהיר ואינטואיטיבי
- החלקת מסכים במובייל בין סוגי אימונים
- שמירה אוטומטית בדאטאבייס

### 📊 תרשימים וסטטיסטיקות
- גרפי התקדמות ויזואליים עם Recharts
- מעקב נפח אימונים יומי (30 יום אחרונים)
- תדירות תרגילים וסטטיסטיקות חודשיות
- התקדמות במשקלים לתרגילים מובילים
- שיאים אישיים ופעילות אחרונה

### 🎯 מטרות אישיות
- הגדרת מטרות מותאמות אישית
- קטגוריות: משקל גוף, כוח, סיבולת, מבנה גוף, מטרות אישיות
- מעקב התקדמות בזמן אמת עם פס התקדמות
- ניהול מטרות: עריכה, מחיקה, סימון השלמה

### 🎥 ספריית וידאו
- קטגוריות: תרגילים, מדריכים, מוטיבציה, תזונה
- ניהול וידאו מתקדם (אדמין)
- הטמעת YouTube ישירות באפליקציה

### 📱 מותאם למובייל
- עיצוב רספונסיבי מלא
- מחוות מגע (החלקה בין טאבים)
- כפתורים מותאמים למגע
- טקסט וגדלים מותאמים לכל מכשיר

## 🚀 טכנולוגיות

- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Auth + Real-time)
- **Charts**: Recharts
- **Icons**: Lucide React
- **Build Tool**: Vite

## 🧪 מצב עבודה ללא Supabase (זמני)

כרגע האפליקציה פועלת במצב Local-first ואינה דורשת פרטי Supabase או Google OAuth:
- יצירת פרופיל מתאמן נשמרת ב-`localStorage`.
- רישומי אימונים, תוכניות, סרטונים ומטרות נשמרים בדפדפן המקומי.
- הנתונים זמינים רק באותו דפדפן/מכשיר ואינם מסתנכרנים בין משתמשים או מכשירים.
- ניתן ליצור גיבוי מלא בפורמט JSON ולשחזר אותו מתפריט ההמבורגר (גיבוי מלא / שחזור מגיבוי).
- ניקוי נתוני האתר/הדפדפן עלול למחוק את המידע. מומלץ לייצא גיבוי לפני ניקוי נתונים.

מצב זה מיועד לפיתוח ולהדגמה בלבד. ניהול מאמנים והרשאות במצב מקומי אינו מנגנון אבטחה. בעת חיבור Supabase נחזיר את Google OAuth ונעביר את השמירה למסד נתונים מאובטח.

## 🔐 התחברות עם Google

מסך הכניסה משתמש ב-Supabase Auth עם Google OAuth.

1. ב-Supabase פתח **Authentication → Providers → Google** והפעל את Google provider.
2. צור OAuth Client מסוג Web ב-Google Cloud Console.
3. הוסף ב-Google את כתובת ה-Callback שמציג Supabase תחת **Authentication → URL Configuration** (בדרך כלל `https://<project-ref>.supabase.co/auth/v1/callback`).
4. הזן ב-Supabase את Google Client ID ואת Client Secret.
5. תחת **Authentication → URL Configuration → Redirect URLs** הוסף את כתובות האתר שבהן האפליקציה פועלת, למשל `http://localhost:5173/**` ואת כתובת הייצור שלך.
6. ודא שמשתני הסביבה `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY` מוגדרים בסביבת הפיתוח/הפריסה.

האפליקציה מבקשת בחירת חשבון Google בכל התחברות ומחזירה את המשתמש לכתובת שממנה התחיל את תהליך ההתחברות. אין לשמור את Google Client Secret או מפתחות שירות בקוד צד הלקוח.

## 🗄️ מבנה הדאטאבייס

המערכת משתמשת ב-Supabase עם PostgreSQL:

- **users** - פרטי משתמשים
- **workout_logs** - רישומי אימונים
- **goals** - מטרות אישיות
- **videos** - ספריית וידאו

כל הטבלאות מוגנות ב-Row Level Security (RLS).

## 👑 מערכת אדמין

המערכת כוללת מצב אדמין למשתמשים מורשים:

1. ערוך את `src/utils/admin-config.ts`
2. הוסף מייל למערך `ADMIN_EMAILS`
3. התחבר עם המייל המורשה
4. הפעל מצב אדמין

**הרשאות אדמין:**
- עריכת תוכניות אימון
- ניהול ספריית וידאו
- גישה לכל הנתונים
